Run CUORE

CUORE runs on your computer, so your video stays there.

This website explains CUORE. The measuring app is a small program you run yourself: the camera, the analysis and every reading stay on your machine. Setup takes about ten minutes.

01What you need

Before you start

  • A computer with a webcam: macOS, Windows or Linux.
  • Python 3.12, and about 2 GB of free disk space for the analysis libraries.
  • A current browser: Chrome, Edge, Safari or Firefox.
  • Steady light in front of you. A bright window behind you makes the heart signal weak.

02Install and start

On your computer

  1. Download CUORE 
    git clone -b web-ui https://github.com/LeoSLayer1-Arif/cuore.git
cd cuore
  2. Create a private Python environment and install 
    python3.12 -m venv venv
venv/bin/pip install -r requirements.txt
    On Windows use venv\Scripts\pip and venv\Scripts\python.
  3. Start the server 
    venv/bin/python server.py
    The first start downloads MediaPipe's face-landmark model (a few MB) from Google's public model storage. That is a file download only; nothing about you is sent. It can take a minute.
  4. Open CUORE 
    http://127.0.0.1:5001/app
    Allow the camera when your browser asks, choose a session length, and sit still.

03From your phone

Home Wi-Fi mode

Your phone's video goes to your own computer over your Wi-Fi, is processed in memory there, and is not sent anywhere else.

  1. Start the server in home Wi-Fi mode 
    venv/bin/python server.py --lan
    It prints an https address and an 8-character pairing code.
  2. Open the address on your phone The phone and computer must be on the same network. A phone hotspot works when public Wi-Fi blocks devices from seeing each other. The browser warns that the certificate isn't trusted: it was made on your computer for that address. Safari: Show Details › visit this website. Chrome: Advanced › Proceed.
  3. Enter the pairing code Only paired devices can send frames or see readings. Restarting the server issues a new code.

04If something's off

Common fixes

Port 5000 doesn't work on a Mac
macOS uses it for AirPlay. CUORE uses 5001; another port works with --port 5002.
“Camera access is blocked”
Allow the camera for the page in your browser's site settings, then try again.
Heart signal stays weak
Face a lamp or window, hold still and keep your whole face in view. Breathing and blinks keep measuring meanwhile.
The phone can't open the address
Check both are on the same network, allow incoming connections for Python if your computer asks, or use a phone hotspot.
